Installation

Up and running in 2 minutes.

Load unpacked directly in Chrome for personal or developer use.

STEP 01

Clone Repository

Download or git clone the repo locally to your machine.

git clone https://github.com/...
STEP 02

Load Unpacked

Open chrome://extensions, toggle Developer Mode, click Load unpacked.

STEP 03

Add API Key

Open ReplyGenie Options and paste your OpenAI key (starts with sk-proj-).

STEP 04

Start Replying

Visit x.com, click ✨ Reply on any post, and paste the auto-copied reply.
