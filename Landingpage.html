25 Structural Angles

Rotates through 25 distinct reply structures — sharp questions, reframes, data points, or practical observations — so your replies never feel formulaic.

🧠

Local Voice Learning

Quietly learns from your actual manual replies on X to match your vocabulary, sentence length, and unique style over time.

⚡

Instant Template Short-Circuit

Detects common intents (congratulations, thanks, connections) and instantly suggests templates without burning OpenAI API tokens.

🔒

Privacy & BYO Key

Your OpenAI API key is saved exclusively in Chrome local storage. API requests go directly from your browser worker to OpenAI.

📋

1-Click Auto Copy

Click ✨ Reply, get a generated reply, and it's placed right on your clipboard ready to paste into X's reply box immediately.

🎛️

Custom Tone & Length

Fine-tune replies by tone (Witty, Professional, Friendly, Supportive) and strict length bounds (Short punchy, Medium, Long detailed).

Get Started in 2 Minutes

Load unpacking instructions for testing or personal setup.

01

Download / Clone

Clone the repository from GitHub to a permanent folder on your computer.

02

Load Unpacked

Go to chrome://extensions, turn on Developer Mode, and select Load unpacked.

03

Add API Key

Click ReplyGenie Options and paste your OpenAI API Key (starts with sk-proj-).

04

Start Replying

Open x.com, click ✨ Reply on any tweet, and paste the generated response.
